Orchestration Enablers ()
Definition: Orchestration Enablers ABB is a Grouping Component that refers to the components and practices that support the development and deployment of orchestration applications. Source: ETSI Network Functions Virtualisation Standard Source reference: https://portal.etsi.org/NFV/NFV_White_Paper2.pdf Interoperability Dimension: Structural IoP LOST view: Technical view - application Interoperability Saliency: The Orchestration Enablers Grouping ABB is salient for interoperability because it contains both, application services and components, that can enable the deployment and development of orchestration services.
